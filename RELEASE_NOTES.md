# Media Downloader 1.1.1

- Save playlist downloads in a folder named after the playlist, with numbered files in playlist order.
- See whether browser verification succeeded or failed. The verification notice clears automatically.
- Download multiple music tracks at once, up to the configured parallel download limit. A provider may ask to verify each worker separately.

Extract the ZIP and move the app to Applications. The app is ad-hoc signed and has not been notarized by Apple. Enable Allow Unsigned Extensions in Safari to use the bundled extension.
