# YouTube Downloader 1.0

- One lightweight Universal ZIP for Intel and Apple Silicon. On first launch, the app downloads a signed engine kit and displays setup progress.
- The engine can update independently of the app. Check for app updates from the YouTube Downloader menu or configure automatic checks in Settings.
- Includes standard copy support with ⌘C and a compact setup window.

Extract the ZIP and move the app to Applications. First-time engine setup requires internet access. The app is ad-hoc signed and has not been notarized by Apple.
