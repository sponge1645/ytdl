# Media Downloader 1.1

- Download individual tracks and expand music albums and playlists into the download queue. The selected source and track determine which audio formats are available.
- Save music with tags and embedded cover artwork when available. Reinstall Spotify and Apple Music extensions from Settings, and paste a verification return link into the app if Safari does not return automatically.
- Add YouTube videos to the queue directly from Safari with the Download button.
- Scroll large queues with on-demand thumbnails, select multiple rows with Shift or Command, and remove selected rows with Delete.
- Includes a Universal app for Intel and Apple Silicon on macOS 11 or later. The signed video tool kit installs on first launch, and music downloads use Python 3.

Extract the ZIP and move the app to Applications. The app is ad-hoc signed and has not been notarized by Apple. Enable Allow Unsigned Extensions in Safari to use the bundled extension.
