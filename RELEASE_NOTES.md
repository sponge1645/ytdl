# Media Downloader 1.1.1

- Save albums and playlists in named folders. Playlist files are numbered in playlist order.
- Download two tracks with Automatic or the same manually selected music source in parallel through one engine session when the parallel download limit allows it.
- Automatic searches the next source for a track when its current provider times out or fails.
- Change the source for queued or paused audio tracks before they start again.
- Use ⌘A to select all rows. Press Delete repeatedly to remove consecutive rows.
- Working messages clear when their tasks finish. Browser verification shows a brief success or failure notice.

Extract the ZIP and move the app to Applications. The app is ad-hoc signed and has not been notarized by Apple. Enable Allow Unsigned Extensions in Safari to use the bundled extension.
